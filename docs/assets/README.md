# LeoBridge 品牌素材

以项目所有者在 2026-11-03 提供的狮头图片为基础，去除白底并描摹为矢量轮廓；保留原图的朝向、鬃毛和面部特征。横幅使用炭黑渐变与银白，保留狮头、LeoBridge 字标、英文标语、中文简介和右侧双协议分支图，不展示部署技术标签。

| 素材 | 用途 |
| --- | --- |
| [logo.svg](logo.svg) | 640 × 640，透明底炭黑标志，矢量母版 |
| [logo.png](logo.png) | 同尺寸透明 PNG，供不支持 SVG 的场景使用 |
| [后台图标](../../web/admin/logo.svg) | 炭黑圆角底、银白色狮头，侧栏、登录页及 favicon 共用 |
| [wordmark.svg](wordmark.svg) | 730 × 170，透明底炭黑艺术字标，已转为矢量路径 |
| [readme-banner.svg](readme-banner.svg) | 1600 × 520，可编辑横幅 |
| [readme-banner.png](readme-banner.png) | README 使用的固定渲染，避免字体差异影响排版 |

主色：炭黑 `#25292e`，搭配银白 `#f3f4f5`。横幅背景由 `#303439` 过渡到 `#171a1e`；图标使用炭黑底银白图形，独立标志使用透明底炭黑图形。

管理面板默认使用同一炭黑银白夜间体系，也支持浅灰白天模式及跟随系统。颜色变量集中在 `web/admin/styles.css`，白天模式通过 `data-theme="light"` 切换；主按钮在深浅背景上保持对比，错误与未验证状态各自保留明确提示色。

字标采用粗斜体衬线，调整字距并延伸 L 的下部收笔，在保留完整拼写的同时增加识别特征。`wordmark.svg` 和横幅中的 LeoBridge 均已转为矢量路径，无需安装字体即可保持字形一致。

修改狮头时，以 `logo.svg` 中的路径和变换为准，同步后台图标与横幅中的对应图形，再导出两份 PNG。横幅的辅助文字使用系统字体；修改后需在有中文字库的环境重新导出并目视检查 PNG。主字标已转曲，修改品牌名需要更新路径，并同步独立字标与横幅。所有 SVG 均为自包含资源，无外部图片、字体请求或脚本。素材已随仓库保存，正常项目构建不需要图形工具或额外依赖；现有构建会将后台图标复制到管理资源目录。
