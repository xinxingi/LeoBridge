# LeoBridge 品牌素材

以项目所有者在 2026-11-03 提供的狮头图片为基础，去除白底并描摹为矢量轮廓；保留原图的朝向、鬃毛和面部特征。横幅使用深墨绿与薄荷白，分叉连线表示一个数据源输出 CFSM、Komari 两套协议。

| 素材 | 用途 |
| --- | --- |
| [logo.svg](logo.svg) | 640 × 640，透明底深色标志，矢量母版 |
| [logo.png](logo.png) | 同尺寸透明 PNG，供不支持 SVG 的场景使用 |
| [后台图标](../../web/admin/logo.svg) | 深绿圆角底、浅色狮头，侧栏、登录页及 favicon 共用 |
| [readme-banner.svg](readme-banner.svg) | 1600 × 520，可编辑横幅 |
| [readme-banner.png](readme-banner.png) | README 使用的固定渲染，避免字体差异影响排版 |

主色：深墨绿 `#102b29`、标志深色 `#10212b`、薄荷白 `#dcf6e8`。图标背景为 `#173c36`。透明标志适用于浅色背景，后台图标适用于深浅背景。

修改狮头时，以 `logo.svg` 中的路径和变换为准，同步后台图标与横幅中的对应图形，再导出两份 PNG。横幅 SVG 使用系统字体；修改文字后需在有中文字库的环境重新导出并目视检查 PNG。所有 SVG 均为自包含资源，无外部图片、字体请求或脚本。素材已随仓库保存，正常项目构建不需要图形工具或额外依赖；现有构建会将后台图标复制到管理资源目录。
