# 兼容范围与限制

LeoBridge适配妙妙屋X探针数据，提供独立的CFSM与Komari展示协议。既有浏览器验收仅覆盖以下历史适配包（已不随项目交付）：

| 主题 | 固定上游版本 | 展示能力 |
| --- | --- | --- |
| CFSM默认前台 | `609cc0b0998793510453be8eadced2064b28ad7d` | 首页、详情、系统与Ping历史、实时更新 |
| Komari 官方默认前台 | `bed58b589da63232a17681b1dbaed9eab2423078` | 首页、详情、系统与Ping/丢包历史、实时更新 |

两个历史适配包曾通过本地真实数据与浏览器验证，官方 Komari 前台结果见[验收记录](komari-default-acceptance.md)。官方前端许可未声明为 MIT，详见[来源档案](../references/retired-themes/README.md)。旧 Adhesive Note 安装的协议保留。商店原包与内置适配包不同；发现或安装成功不代表兼容。主题配置编辑、卸载及孤立资源清理UI尚未提供。Komari的raw/redirect声明保留但不在管理页执行，managed默认值按安装版本传入HTTP/WS；尚无配置编辑UI。

LeoBridge提供独立的主题管理站，不提供CFSM或Komari的采集、服务器管理、终端、远程控制与告警功能。上游Token不提供给主题。single模式的正式主题及预览均与管理后台同源，只应预览和启用可信主题；需要隔离时使用isolated模式。

## 当前主题获取方式

默认不内置第三方主题，由管理员从商店按需安装。先展示实际固定版本、来源和许可文件，再主动勾选确认；安装时重新校验同一版本及摘要。记录知情决定，不作授权判断。许可信息缺失不代替包安全与兼容性检查；所有新商店安装仍标为未验证，详见[主题管理](../themes.md#主题获取与许可信息)。历史适配包兼容结论不覆盖商店原版。

本轮实际检查了商店原版Emerald及Adhesive Note：两者首页/详情可读取真实数据，但发现未知字段被原主题显示为零、免费或无限；Emerald七天图表还要求原CFSM管理登录。它们继续保持未验证，不宣称完整兼容，见[按需安装验收记录](theme-store-transition.md)。

## 2026-11-03 通用资源与协议修复

资源完整性不再等同于“所有依赖必须在ZIP里”。支持主题固定来源按需拉取、官方公共图像回退、公共CSS库字体依赖及HTTPS外链；仍核对摘要、路径及大小，详见[主题管理](../themes.md)和[资源来源](../references/theme-resource-sources.md)。不按主题名改写原包，不伪装完整CFSM/Komari管理后端。

真实妙妙屋X快照11/11节点具有有效CPU、内存、磁盘和网络速率；同一快照与中立模型、CFSM、Komari转换比较0差异，CPU真零保留。此前Fixture Missing是缺值合成节点，不能当作真实源缺CPU的证据。

按用户最新要求，展示页已移除“数据说明”，保留原主题显示逻辑；不支持的指标及原主题可能显示0、免费或无限的限制继续记录在本文。Komari Ping统计省略无法推导的可选分位数等字段，避免原主题对null调用toFixed，不伪造统计值。CFSM提供原生is_online别名，避免Horizon把离线误当在线。Emerald 1.0.16原版对缺失负载直接调用toFixed，合成缺值/离线节点会无法渲染卡片，属于已确认的原主题缺值边界限制；真实11台节点负载完整。具体原包浏览器复验结果见[通用桥接验收](theme-bridge-acceptance.md)。

## 数据转换


| 源端事实 | 桥接及CFSM行为 | 证据/限制 |
| --- | --- | --- |
| `cpu_pct` | 百分比；0保留，缺失/无效为未知 | 源文档、真实结构及转换测试；不是重新采集 |
| `mem_* / disk_*` | 中立模型byte，CFSM容量除以1024²为MiB | 已对照默认前台格式化消费 |
| `download_speed / upload_speed` | `net_in_speed / net_out_speed`，B/s不缩放 | 源文档与默认前台消费一致 |
| `cpu_threads` | 逻辑核心；不把物理`cpu_cores`无条件当逻辑线程 | 未知保持缺省 |
| `online` | 显式true/false/null优先 | 上游不可达、数据过期不是服务器离线 |
| `last_seen / uptime` | 离线源时间转毫秒；在线采用桥接观察时间；启动时间标记推算 | 不声称取得源端精确在线采样时间或开机时刻 |
| `region_country / region` | 已知国家编码/Emoji转地区代码；未知不编造 | 图标优先来自主题，缺失时读取固定官方公共资源 |
| Ping目标 | 显式key→CFSM槽位，不按数组位置或ISP唯一性推断 | 源目标数量可变；桥接最多8槽，未选目标不展示 |
| Ping `-1` | 无数据；保持CFSM `false`/空点语义 | 不能改为0延迟；只有明确100%丢包且无有效RTT才表示超时 |
| `traffic_* / cumulative_*` | 累计、月流量和计费字段当前不映射，显示未知 | 计费用量为configured_period、来源xray；网卡/开机累计为current_boot。不同口径不得混用 |
| Swap/GPU/磁盘IO/进程等 | 未支持，不填0或编造历史 | 协议保留未知；各主题的实际显示需单独验收 |

## 历史范围

支持的上游范围为1h、6h、24h和7d，对应桶宽为300、600、1800和7200秒。七天选项要求上游声明`history_days>=7`。更短的展示范围由已支持的范围裁剪；不会因此提高采样精度。2d至6d的独立上游参数不在已验证范围内。

`buckets`表示预期容量，不能当成实际采样点数。每项系统指标拥有独立的`{t,value}[]`，按真实时间合并，不按数组下标拼接。历史不足时保留缺口，不插值、不补零，也不保证完整七天覆盖。

Ping桶没有独立时间戳，按上游消费者的规则计算：

```text
timestamp_ms = (floor(generated_at / bucket_sec) * bucket_sec
                - (buckets.length - 1 - index) * bucket_sec) * 1000
```

系统时间由Unix秒转为CFSM毫秒；Komari按其消费者格式输出。图表以实际桶宽判断断点。上游返回的桶宽必须匹配已核实档位，避免静默降档。

## 稳定身份及无法消除的限制


源接口不提供已确认的不可变服务器ID，历史参数仍为当前公开数组下标。桥接配置保存不透明稳定ID和**显式描述选择条件**；每次快照都重新一对一匹配并取得当前下标。名称不是隐含唯一键，可联合其他允许的公开属性，但这些属性也不是不可变ID。

- 每台公开服务器必须恰好匹配一项绑定；重复、重叠、缺少、未绑定或属性变化都明确失败，不静默映射。正常重排可保持桥接ID。
- 历史请求前后分别获取新快照并比较整组ID顺序；变化时丢弃结果并返回409。缓存读取仍校验身份。
- 改名、名称隐藏、配置/硬件变化、添加或移除服务器时需要审查选择条件；保留原桥接ID显式维护，不靠重新随机生成全部ID掩盖问题。
- 两次快照间重排再复原，或另一台完全复用同组描述属性，当前API无法区分。运行约束是**历史读取期间不改公开列表顺序或身份属性**；若无法满足，必须等待上游稳定公开ID及按ID查询接口。前后检查不是原子身份保证。

## 实时、故障与访问策略

每访客一条上游连接，关闭页面时清理连接和定时器。断线从1秒退避至30秒；45秒未收到完整源帧时标记过期并重连，连接每10分钟更新。连续15秒无完整快照时，每5秒尝试HTTP快照回退；同一进程/isolate复用3秒缓存并合并并发请求。只有真实读取成功才发送数据，不以旧缓存冒充恢复。

下游`transport`字段区分`websocket`与`poll`。WebSocket握手或HTTP回退成功不代表持续收到上游原生帧，也不保证固定5秒更新。上游可能返回503；连接频率和可用性取决于源端。

历史读取包含前快照、并行system/Ping查询及后快照，每段上游请求截止30秒，前台允许110秒。身份、隐私或无效数据变化会使旧请求失效；单个实时连接的运输故障不应清空跨协议共享缓存。

协议区分未知指标、真实零值、离线、数据过期和上游故障；商店原包是否正确呈现这些状态仍需逐包验收。离线、隐藏、关闭采集及重排等边界具有合成测试覆盖；合成结果不代表已在所有真实上游版本观察到相同行为。上游主控及Agent具体版本尚未确认。

Token仅用于服务端访问配置的源，拒绝重定向。展示站的local/public/private策略与主题管理认证独立；private保护HTML、资源、HTTP和WebSocket。

## 部署边界

用户部署面向[Docker Hub镜像](../deployment/docker.md)和[预编译运行包](../deployment/local.md)，目前公开发行产物尚未发布，文件存储按单站、单进程、单副本运行。Node实时访客连接上限为50；尚无生产容量或高可用保证。跨应用版本升级/降级尚未完成完整验证。

本地`leobridge.sh`只负责后台启停和状态/日志管理，不下载Node、不安装pnpm或依赖、不构建。运行包包含Node、已构建应用及生产依赖，发行打包由开发者完成。上一轮源码自动引导验证只保留为历史，不能代表当前运行包或已公开发布。脚本不提供开机自启或崩溃自动拉起；管理与打包检查不增加主题兼容结论。 当前macOS arm64实际运行包已完成无系统Node/npm/pnpm的解压启停、管理页及改密后重启持久化检查；Linux运行包实机验收、GitHub公开Release和Docker Hub发布均未执行。

[Cloudflare Workers](../deployment/workers.md)留待后续适配，当前不作为已支持的部署方式。保留实现中，R2存主题静态包，单站Durable Object存主题元数据、管理会话及私有数据源配置；不使用D1，不持久化采集历史。Workers尚无跨isolate共享限流。

每个部署环境都应检查上游访问和前台行为；本地部署无需域名或证书。对外访问时，域名、TLS及反向代理由部署者配置并单独验证。构建、合成测试或本地运行不能替代目标环境验证。架构设计见[ADR 001](../decisions/001-theme-protocol-boundaries.md)。
