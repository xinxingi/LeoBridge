# Jiwo社区原生前台

## 来源与商店条目

[Jiwo Probe · 鸡窝状态站](https://github.com/chnnic/jiwo-probe)是社区作者chnnic基于妙妙屋X独立探针前台开发的公开源码版本。本次源码审计固定于[`62cf6932bea20b7ead20c3c2d3b0e44ffdc06b29`](https://github.com/chnnic/jiwo-probe/tree/62cf6932bea20b7ead20c3c2d3b0e44ffdc06b29)。它具有多个内置界面，部分采用独立目录和懒加载，但统一构建部署，并非一组可独立安装更新的主题包。

LeoBridge在「妙妙屋 X 原生主题商店」中登记一个`jiwo-probe`条目，名称为「Jiwo Probe · 鸡窝状态站」，标签为「社区 · Jiwo」。官方`mmwx-probe`条目保留。安装整套Jiwo后，可按安装版本选择已发现的外观，或输入上游支持的自定义标识；填写名称不生成缺少的主题实现。

## 聚合与更新方式

本项目只维护来源登记、构建与协议接入，不将Jiwo源码搬入LeoBridge仓库，不另存第三方源码副本或修改上游文件。运行时从选定仓库的main解析固定提交，验证该提交Git树、路径、文件类型、大小和blob摘要，再在临时目录下载源码和锁定依赖。构建结束或失败均清理临时目录；安装保存静态产物、来源许可及固定公共资源索引，公共资源沿用该安装来源与版本按需下载。

官方与社区来源分别检查更新，缓存及并发构建按来源标识和提交隔离。准备、确认及安装复用同一个来源与固定版本；上游main随后移动不会更换已确认内容。更新作为独立版本安装，不自动启用，保留现有预览、启用和回退流程。首次准备需要网络、临时磁盘和构建内存，Node运行包或Docker提供构建能力；未扩大Workers支持范围。

构建使用LeoBridge自有esbuild配置，不执行上游部署、构建配置或npm生命周期脚本。Jiwo的主入口和Ran独立`map.html`均参与构建，`@`按该来源指向临时目录中的`src/ran`；来源NOTICE和依赖许可随静态包保留。

## 协议与适用边界

### 外观优先级

另按用户安装的固定提交[`12dfda58043745d505021026e75354160f545378`](https://github.com/chnnic/jiwo-probe/tree/12dfda58043745d505021026e75354160f545378)核对`src/use-probe.ts`的`applyAppearance/getThemeOverride/setTheme`及`src/App.tsx`：前台手动选择保存在浏览器`localStorage`的`mmwx-probe-theme-override`中，优先于接口的`appearance.theme`，刷新仍保留。前台选择“跟随主控”会移除该覆盖，随后使用桥接器下发的默认外观；后台也选择“跟随主控”时才透传真实主控外观。因此后台卡片标为“默认外观”，不表示强制覆盖访客选择。此项记录的是当时的固定源码核对，当时未在浏览器重新验收该提交；后续用户兼容确认见下方验证记录。

Jiwo使用独立原生协议`mmwx-native-v1`取得快照、历史和实时数据，不经CFSM或Komari协议转换。即使界面沿用Emerald、Ran等名称，也不能据此等同为对应生态的原主题包。展示槽位继续由显式节点绑定解析，历史查询前后核对身份，公开字段和名称隐藏策略保持。

仅在Jiwo安装上下文提供两个可选辅助接口：

| 接口 | LeoBridge行为 |
| --- | --- |
| `GET /api/theme-config` | 返回空配置对象，使用前台内置显示默认值，不引入上游Worker环境变量配置界面 |
| `GET /api/visitor` | 返回UNKNOWN/null等明确未知值，不从不可信请求头推断IP或虚构Cloudflare地理资料 |

`/api/stream?delta=1`仍使用原生完整快照；Jiwo声明接受增量帧不要求桥接器生成增量。主控Passkey登录不代理，其他只存在于Jiwo Worker中的功能不能因为前台构建成功便视为已提供。
